# Vellum Lite — Student Portfolio Website Template

A free, no-build HTML template for a clean student portfolio. Edit one file (`js/config.js`), then publish it at no cost on [GitHub Pages](https://pages.github.com/) or [Netlify](https://app.netlify.com/drop).

This Lite version includes the **Ivory** theme and the core sections: About, Education, Projects, and Contact.

**Want the full template?** Vellum Pro adds two more color themes (Midnight, Harbor), internships & experience, skills, certificates, recommendations, a print-friendly résumé view, and no footer credit. Get it at **[cuoitudo.gumroad.com](https://cuoitudo.gumroad.com)**.

---

## Preview the demo

Open `index.html` in your browser. The demo content is fictional (Maya Tran, Harbor University) — replace it with your own.

## Customize

1. Open `js/config.js` in a text editor.
2. Change the name, headline, about text, education, projects, email, and social links. Keep the commas and quotation marks.
3. Replace `assets/portrait.svg` with your photo and set `photo: "assets/me.jpg"` (or `.png`).
4. Save, then refresh the browser.

A longer walkthrough in English and Vietnamese is included in the [Pro template](https://cuoitudo.gumroad.com).

## Publish for free

**GitHub Pages:** create a public repository, upload these files (keep the folders), then go to **Settings → Pages** and deploy from the `main` branch, `/ (root)`.

**Netlify:** drag this folder onto [app.netlify.com/drop](https://app.netlify.com/drop).

# Vellum Lite — Mẫu website portfolio cho sinh viên

Mẫu HTML miễn phí, không cần cài đặt, để làm một trang portfolio gọn và lịch sự. Chỉ cần sửa file `js/config.js`, rồi đăng miễn phí lên [GitHub Pages](https://pages.github.com/) hoặc [Netlify](https://app.netlify.com/drop).

Bản Lite gồm bảng màu **Ivory** và các phần chính: Giới thiệu, Học vấn, Dự án, Liên hệ.

**Muốn bản đầy đủ?** Vellum Pro có thêm hai bảng màu (Midnight, Harbor), phần kinh nghiệm, kỹ năng, chứng chỉ, lời nhận xét, bản in résumé, và không bắt buộc ghi nguồn ở chân trang. Mua tại **[cuoitudo.gumroad.com](https://cuoitudo.gumroad.com)**.

## Xem bản demo

Mở `index.html` bằng trình duyệt. Nội dung mẫu là hư cấu (Maya Tran, Harbor University) — hãy thay bằng thông tin của bạn.

## Cách chỉnh

1. Mở `js/config.js` bằng trình soạn thảo văn bản.
2. Đổi tên, mô tả, học vấn, dự án, email và mạng xã hội. Giữ nguyên dấu phẩy và dấu ngoặc kép.
3. Thay `assets/portrait.svg` bằng ảnh của bạn, rồi sửa `photo: "assets/me.jpg"`.
4. Lưu file và tải lại trang.

Hướng dẫn dài hơn (tiếng Anh và tiếng Việt) nằm trong [bản Pro](https://cuoitudo.gumroad.com).

## Đăng miễn phí

**GitHub Pages:** tạo kho công khai, tải các file này lên (giữ nguyên thư mục), vào **Settings → Pages**, chọn nhánh `main`, thư mục `/ (root)`.

**Netlify:** kéo cả thư mục thả vào [app.netlify.com/drop](https://app.netlify.com/drop).

## Giấy phép

Dùng miễn phí cho một website portfolio cá nhân của sinh viên. Vui lòng giữ link ghi nguồn ở chân trang tới [cuoitudo.gumroad.com](https://cuoitudo.gumroad.com). Xem thêm `LICENSE.txt`. Không được bán lại mẫu.
